      <h2 class="ui dividing header">Installation</h2>
<p>The package is distributed as part of the <a href="http://bioconductor.org/packages/EBImage">Bioconductor</a> project.
To install this package, start R and enter:</p>
<pre><code>install.packages("BiocManager")
BiocManager::install("EBImage")
</code></pre>
<h2 class="ui dividing header">Documentation</h2>
<p>For an overview of the package functionality, see the <a href="http://bioconductor.org/packages/devel/bioc/vignettes/EBImage/inst/doc/EBImage-introduction.html">package vignette</a>.</p>
<p>Once you install the package, you can access individual man pages by a call to, e.g., <code>?Image</code>.</p>
<h2 class="ui dividing header">FAQ</h2>
<p>See <a href="http://stackoverflow.com/search?q=user%3A2792099+%09is%3Aanswer+EBimage">my answers on Stack Overflow</a>.</p>
<h2 class="ui dividing header">Bug reports and feature requests</h2>
<p>Bug reports, feature requests, or any other issues with the package should be reported at <a href="https://github.com/aoles/EBImage/issues">https://github.com/aoles/EBImage/issues</a>.</p>
